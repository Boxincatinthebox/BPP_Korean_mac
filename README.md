# BPP 한글판 (macOS)

[BazaarPlusPlus](https://bazaarplusplus.com) 한글판 v5.7.0-ko.2의 macOS 배포본입니다.
Windows 전용 파일과 BepInEx core는 포함하지 않습니다.

## 설치

1. 게임을 종료합니다.
2. [최신 릴리스](https://github.com/Boxincatinthebox/BPP_Korean_mac/releases/latest)에서 zip을 받습니다.
3. 게임 폴더(`~/Library/Application Support/Steam/steamapps/common/The Bazaar`)에 압축을 풀어 덮어씁니다.

## 라이선스

- BazaarPlusPlus — MIT
- BepInEx — LGPL-2.1

라이선스 전문은 zip 안의 `LICENSES/` 폴더에 있습니다.
이 저장소는 비공식 한글 패치이며 BazaarPlusPlus 및 The Bazaar 개발사와 관련이 없습니다.
